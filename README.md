## 📖 Sobre el proyecto

Este repositorio contiene el proyecto práctico del **Curso de TailwindCSS** de [Platzi](https://platzi.com), impartido por Oscar Barajas Tavares. El objetivo es construir sitios web modernos y responsivos usando clases de utilidad, dominando layouts, integración con frameworks, personalización, plugins y buenas prácticas para aplicaciones eficientes.

## 🧠 Conceptos practicados

| Área                       | Temas                                                                               |
| -------------------------- | ----------------------------------------------------------------------------------- |
| Introducción               | Por qué Tailwind domina el frontend, instalación con Node, watch mode               |
| Fundamentos                | Clases de utilidad, tipografía, cajas (margin, padding y bordes)                    |
| Colores                    | Paletas, degradados y personalización de colores                                    |
| Diseño responsivo          | Breakpoints, container y max-width                                                  |
| Layouts                    | Flexbox, CSS Grid y cuándo usar cada uno                                            |
| Integración con frameworks | Tailwind CSS con Astro y Next.js                                                    |
| Personalización y plugins  | Configuración en Astro, plugins de forms, aspect ratio y Typography (clase `prose`) |
| Flujo de trabajo con IA    | Tailwind CSS con IA y plantillas Astro                                              |

## 🚀 Cómo ejecutarlo localmente

```bash
# 1. Clona el repositorio
git clone https://github.com/joedudev/curso-tailwind-platzi.git

# 2. Entra a la carpeta
cd curso-tailwind-platzi

# 3. Instala las dependencias
npm install

# 4. Inicia el servidor de desarrollo
npm run dev
```
